# Projeto Senior 09 - Rogii Wellbore Geology Prediction

## 📌 Visão Geral
Este projeto foca na predição de geologia de poços (Wellbore Geology) utilizando dados de perfuração e geofísica. O objetivo é automatizar a identificação de formações rochosas para otimizar operações de perfuração e reduzir riscos geológicos.

## 🛠️ Stack Tecnológico (Planejado)
*   **Linguagem:** Python
*   **Processamento:** Pandas, Scikit-Learn / XGBoost
*   **Visualização:** Plotly / Matplotlib
*   **Dataset:** Rogii Wellbore Geology Prediction (Kaggle)

## 📂 Estrutura do Projeto
*   `/data/raw`: Dados originais do Kaggle.
*   `/data/processed`: Dados limpos e prontos para modelagem.
*   `/notebooks`: Análise exploratória e experimentos de modelos.
*   `/src`: Scripts modulares para processamento e treinamento.
*   `/reports`: Relatórios executivos de impacto e ROI.
